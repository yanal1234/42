# Libft

Libft is the first project of the 42 Core curriculum.

The goal of this project is to create a personal C library by reimplementing standard C library functions and adding useful functions for working with strings, memory, and linked lists.

## Features

### Part 1 — Libc Functions

- Character checks
- String manipulation
- Memory manipulation
- Character conversion
- Number conversion
- Memory allocation
- String duplication

### Part 2 — Additional Functions

Additional functions for working with strings and memory.

### Part 3 — Linked Lists

Implementation of singly linked-list functions using the `t_list` structure.
